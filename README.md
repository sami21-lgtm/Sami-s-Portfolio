# 🚀 MD. Emtiaz Hossain Sami — Developer Portfolio

A modern, high-performance, and responsive portfolio website built with a sleek dark-themed UI, glassmorphism aesthetics, interactive animations, and smooth filtering capabilities. 

Designed for **Software Engineers**, **Front-End Developers**, and **Competitive Programmers**.

---

## ✨ Features

- 🎯 **Sleek Cyber/Dark Aesthetic**: Premium dark theme with vibrant red neon accents and subtle glassmorphism effects.
- 📱 **100% Fully Responsive**: Fluid design that adapts seamlessly to Mobile, Tablet, Laptop, and Desktop screens.
- ⚡ **Interactive Cursor & Glows**: Dynamic dual-ring custom follower cursor and glow animation effects.
- 🎓 **Verified CV Node & Timeline**: Dedicated academic roadmap featuring Daffodil International University, Dhaka City College, and DHSS.
- 🗂️ **Category-Based Project Filter**: Filter portfolio items by *Management*, *Festive & UI*, or *Web Tools*.
- 🌓 **Light / Dark Mode Switch**: Instant theme toggling with state persistence saved to local storage.
- 📩 **Interactive Contact & Toast**: Functional message form with custom visual toast notifications.
- 📥 **Direct Resume Download**: Quick-access PDF download buttons integrated in navigation and CV nodes.

---

## 🛠️ Tech Stack

- **Structure**: [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
- **Styling**: [Tailwind CSS (v3)](https://tailwindcss.com/) & Custom CSS3 animations
- **Scripting**: Pure JavaScript (Vanilla ES6+)
- **Iconography**: [Iconify Framework](https://iconify.design/)
- **Typography**: [Inter Font](https://fonts.google.com/specimen/Inter) via Google Fonts
